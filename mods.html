How to install

Four steps

  1. Pick Fabric or NeoForge as the loader when creating the instance — most of the list above assumes Fabric.
  2. Search for the mod in the instance's content tab. Dependencies such as Fabric API are pulled in automatically.
  3. For shaders, switch the renderer to Zink or MobileGlues and install Iris together with a shader pack.
  4. If it crashes, the crash recovery centre points at the suspected mod — toggle it off and relaunch.
